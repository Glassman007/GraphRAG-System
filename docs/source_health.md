# Source Health

Source health combines, but does not conflate, connection and ingestion state. Source list/detail exposes last connection test, connection message, last attempted sync, last successful sync, latest run, current cursor, last error, failed records, open identity reviews, and derived staleness.

The `/sources` UI summarizes connected, healthy, stale and attention-required sources. Fixture/demo sources are visibly marked and are never presented as live integrations.
